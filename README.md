# Daikin Home Hub Modbus

A Home Assistant custom integration for a **Daikin Altherma 3 series heat pump** connected to a **Daikin Home Hub in Modbus TCP mode**. Requires **Home Assistant 2026.10.2 or newer**.

Tested and working on a physical Altherma 3 M with a Home Hub gateway.
